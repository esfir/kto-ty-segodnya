# Кто ты сегодня?

Короткий опрос настроения для начала онлайн-занятия. React + Vite + TypeScript, обычный CSS. Без регистрации, сервера, аналитики и сохранения ответов.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite.

## Сборка и размещение

```sh
npm run build
npm run preview
```

Папка `dist/` — готовый статический сайт. В Vercel выберите Vite, команду сборки `npm run build` и выходную папку `dist`. Можно разместить на любом статическом хостинге. Данные никуда не отправляются; каждый ученик выбирает на своём устройстве, общего подсчёта нет.

## Изображения и персонажи

Все изображения находятся в `public/characters/`:

| Имя файла | Персонаж |
| --- | --- |
| sloth | Ленивец |
| raccoon | Енот-хулиган |
| cat | Кот в шоке |
| duck | Утка на позитиве |
| panda | Панда-обжорка |
| squirrel | Белка на турбо-скорости |
| fox | Лис в режиме гения |

`*.png` — неизменённые оригиналы. `*.webp` — полноразмерные копии без потери качества. `*-small.webp` — лёгкие версии 480 × 480 для карточек. Все картинки показываются целиком с `object-fit: contain`. Тексты взяты с иллюстраций и не дублируются на экране результата.

Чтобы заменить иллюстрацию, замените PNG с соответствующим именем и пересоздайте WebP:

```sh
python3 -m pip install Pillow
python3 scripts/prepare_images.py
```

Чтобы добавить персонажа, добавьте PNG, запустите скрипт и добавьте запись в `src/activities/mood/characters.ts`. Поле `id` должно совпадать с именем файла без расширения, `phrase` — с подписью на картинке (оно также используется для доступного описания). Для изображений без встроенной фразы установите `phraseInImage: false`.

## Структура

- `src/main.tsx` — общая оболочка приложения.
- `src/activities/mood/` — независимая активность выбора настроения и её данные.
- `src/styles.css` — адаптивная сетка, оформление, анимации и режим уменьшенного движения.

Будущие активности можно добавлять отдельными папками в `src/activities/`. Сейчас реализован только опрос «Кто ты сегодня?».

Клавиатура: Tab для перехода между карточками, Enter или пробел для выбора. После выбора фокус переходит к результату, после возврата — к выбранной карточке. Учитывается системная настройка уменьшения движения.

Сайт: https://esfir.github.io/kto-ty-segodnya/

После изменений в ветке `main` GitHub Actions автоматически собирает и публикует сайт. Настройка репозитория: Settings → Pages → Source → GitHub Actions.

## Две версии для занятий

- Выбор версии для педагога: https://esfir.github.io/kto-ty-segodnya/
- Уютная версия: https://esfir.github.io/kto-ty-segodnya/#kids
- Для подростков: https://esfir.github.io/kto-ty-segodnya/#teens

Ссылки открывают нужную версию напрямую и работают после обновления страницы. Кнопка «Сменить версию» возвращает к выбору оформления. Возрастные отметки на странице выбора — ориентир для педагога.

Новые изображения подростковой версии лежат в `public/characters/teens/`; названия файлов соответствуют основной коллекции. Скрипт `scripts/prepare_images.py` обрабатывает обе папки. PNG сохранены без изменений, полноразмерные WebP — без потери качества. Обе версии используют общую механику выбора и отдельные изображения.
